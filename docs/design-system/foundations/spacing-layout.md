# 간격 · 레이아웃

> 헤더 높이 → D-010

## 간격

4px/8px 단위를 쓴다. Tailwind 기본 spacing(1 = 4px)과 같아서 별도 토큰은 만들지 않는다.

| 원본 이름                  | 값          | Tailwind  | 용도                                      |
| -------------------------- | ----------- | --------- | ----------------------------------------- |
| `space-xs`                 | 4px         | `1`       | 아이콘과 글자 사이                        |
| `space-sm`                 | 8px         | `2`       | 칩 사이, 카드 목록 간격                   |
| `space-md`                 | 16px        | `4`       | **카드 안쪽 여백**                        |
| `space-lg`                 | 24px        | `6`       | 패널 안 섹션 간격, Primary 버튼 가로 여백 |
| `space-xl`                 | 40px        | `10`      | 큰 영역 사이                              |
| `gutter` / `gutter-mobile` | 20px / 12px | `5` / `3` | 열 사이                                   |
| `margin` / `margin-mobile` | 32px / 16px | `8` / `4` | 화면 가장자리 여백                        |

- 4px 단위를 벗어나는 값(`p-[13px]` 등)은 쓰지 않는다.

## 레이아웃

| 영역           | 규칙                                                       |
| -------------- | ---------------------------------------------------------- |
| 헤더           | 높이 `h-16`(64px) 고정                                     |
| 본문           | `h-[calc(100vh-4rem)]`. 헤더 높이를 매직넘버로 쓰지 않는다 |
| 사이드바       | `w-72`(288px)                                              |
| 메인           | `flex-1 p-8`                                               |
| 콘텐츠 최대 폭 | 1280px [원본]                                              |

자세한 클래스는 `components/layout.md`를 본다.
