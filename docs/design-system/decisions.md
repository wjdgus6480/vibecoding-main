# 결정 기록

원본(`source/stitch.md`)을 노트 앱에 적용하면서 내린 결정이다. 다른 문서는 이유를 반복하지 않고 `→ D-번호`로 이 문서를 가리킨다.
결정을 바꿀 때는 기존 항목을 지우지 말고 **상태를 "대체됨 → D-새번호"로 바꾼 뒤** 새 항목을 추가한다.

| 출처   | 뜻                                         |
| ------ | ------------------------------------------ |
| [원본] | `source/stitch.md`에 있는 값·규칙          |
| [파생] | 원본에 없어서 원본을 바탕으로 정한 값·규칙 |

---

### D-001 색상 기준은 설명 글의 브랜드 색 — 2026-10-07 · 유효

- **결정**: 원본 설명 글의 색(노랑 `#FFC700`, 차콜 `#1E1E1E`, 호박 `#F59E0B`, 캔버스 `#F8F8F6`)을 기준으로 한다. YAML 팔레트는 `muted-foreground`(`#5F5E5E`), `destructive`(`#BA1A1A`)에만 쓴다.
- **이유**: 원본 안에서 YAML(`primary #765b00`, 배경 `#fbf8ff`)과 설명 글이 서로 다르다. 설명 글이 실제 브랜드 의도("노란 버튼에 차콜 글자")를 담고 있고, YAML은 Material 3 자동 생성 팔레트로 보인다.

### D-002 커머스 컴포넌트는 노트 앱에 옮겨서 정리 — 2026-10-07 · 유효

- **결정**: 가게·메뉴 카드는 `NoteItem`으로, 배지는 태그 칩으로, 검색바는 앞으로 만들 노트 검색으로 옮긴다. 커머스 전용 컴포넌트는 `reference/commerce.md`에만 둔다.
- **이유**: 쓸 일 없는 규칙이 섞여 있으면 엉뚱한 규칙을 적용할 위험이 있다.

### D-003 폰트는 Plus Jakarta Sans + Pretendard — 2026-10-07 · 유효

- **결정**: `'Plus Jakarta Sans', 'Pretendard Variable', system-ui, sans-serif`. 기존 로고 폰트 Boogaloo는 제거한다.
- **이유**: Plus Jakarta Sans에는 한글이 없다. 영문·숫자는 디자인 시스템 폰트로, 한글은 Pretendard로 표시한다. 원본도 Pretendard를 비슷한 느낌으로 언급한다.

### D-004 토큰 이름은 기존 이름 유지 — 2026-10-07 · 유효

- **결정**: `background`, `card`, `foreground`, `muted`, `muted-foreground`, `border`, `destructive`를 유지하고 `primary`, `secondary`, `accent`, `pastel-*`, `hairline*`을 추가한다. 원본 Material 3 이름(`surface`, `on-surface` 등)은 쓰지 않는다.
- **이유**: 기존 컴포넌트 클래스를 거의 고치지 않아도 된다.

### D-005 라이트 모드만 — 2026-10-07 · 유효

- **결정**: 다크 모드는 범위 밖이다.
- **이유**: 원본에 다크 모드 정의가 없어서, 정하면 추측이 된다.

### D-006 `muted`는 `#F1F1EF` [파생] — 2026-10-07 · 유효

- **결정**: 보조 버튼·사이드바 배경은 캔버스(`#F8F8F6`)보다 한 단계 어두운 `#F1F1EF`.
- **이유**: 원본에는 보조 배경색이 없고, YAML의 `surface-container`(`#eeedf7`)는 보랏빛이라 따뜻한 캔버스와 어울리지 않는다.

### D-007 노랑 위 글자는 항상 차콜, 호박색은 채움에만 — 2026-10-07 · 유효

- **결정**: `primary` 위 흰 글자는 금지한다. `accent`는 글자색으로 쓰지 않는다.
- **이유**: 명도 대비가 노랑 위 흰 글자 1.6:1, 흰 배경 위 호박색 글자 2.1:1로 기준(4.5:1)에 크게 모자란다.

### D-008 노란 Primary 버튼은 한 화면에 하나 [파생] — 2026-10-07 · 유효

- **결정**: 편집기의 **저장**만 노랑이다. 헤더의 **+ 새 노트**는 차콜(Secondary), **취소**는 Ghost.
- **이유**: 헤더와 편집기가 동시에 보이므로, 노랑이 두 개면 주요 액션이 흐려진다.

### D-009 노트 카드 선택은 노랑 링 [파생] — 2026-10-07 · 유효

- **결정**: 선택된 `NoteItem`은 `ring-2 ring-primary` + Level 2 그림자. `border-2`는 쓰지 않는다.
- **이유**: 원본에 선택 상태가 없다. `border` 두께를 바꾸면 선택할 때 카드 크기가 1px 밀린다.

### D-010 헤더 높이 64px [파생] — 2026-10-07 · 유효

- **결정**: 헤더는 `h-16`(64px), 본문 높이는 `h-[calc(100vh-4rem)]`.
- **이유**: 기존 코드는 헤더 높이를 매직넘버 `65px`로 계산했다. 높이를 고정하면 계산이 확실해진다.

### D-011 모서리는 Tailwind 기본 스케일에 대응 [파생] — 2026-10-07 · 유효

- **결정**: `--radius-*`를 재정의하지 않고 같은 값의 Tailwind 클래스를 쓴다(8px → `rounded-lg`, 16px → `rounded-2xl`).
- **이유**: 재정의하면 `rounded-lg` 같은 기존 클래스의 의미가 바뀌어 혼란스럽다.

### D-012 태그 칩은 노랑 파스텔 하나 [파생] — 2026-10-07 · 유효

- **결정**: 모든 태그는 `bg-pastel-yellow`. 태그별 색상은 쓰지 않는다.
- **이유**: 태그별 색상은 태그 명세(`docs/features/tag/spec-fixed.md`)의 범위 밖이다.

### D-013 안내 문구는 해요체 [파생] — 2026-10-07 · 유효

- **결정**: 안내·오류 메시지는 해요체("이미 있는 태그예요"), 버튼은 짧은 명사·동사("저장", "취소").
- **이유**: 원본 브랜드 톤이 "재치 있고 친근하고 가볍게"다.

### D-014 카드 테두리는 `hairline` 토큰 [파생] — 2026-10-07 · 유효

- **결정**: 원본 Elevation의 `rgba(0,0,0,0.04)` / `0.06` 테두리를 `--color-hairline` / `--color-hairline-strong` 토큰으로 정의한다.
- **이유**: 컴포넌트에 `rgba(...)` 임의값을 쓰지 않기 위해서다.

### D-015 문서에 값을 남기되 테스트로 일치를 검사 — 2026-10-07 · 유효

- **결정**: `foundations/*.md` 표에 CSS 변수와 값을 적고, `src/design-system.test.ts`가 그 값이 `src/index.css`의 `@theme`, `preview/index.html`과 같은지 검사한다.
- **이유**: 처음에는 문서에서 값을 빼고 `@theme`만 기준으로 두려 했다. 하지만 문서를 읽을 때 값이 보여야 판단이 빠르고(예: "primary가 노랑인가?"), 테스트가 있으면 값을 중복해 둬도 어긋나지 않는다.
