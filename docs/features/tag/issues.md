## #1 메모에 태그 추가/삭제

**상태**: 구현됨 · 체크리스트 1~3번은 자동 테스트(`TagInput.test.tsx`)로 확인, 4번은 브라우저 확인 필요, 5번 미충족 (아래 "남은 작업")
**요구사항**: `prd.md` F1 · 세부 규칙 `spec-fixed.md`

### 화면에서 확인하는 방법

노트를 하나 열면 제목 아래에 태그 칩과 입력창이 보인다. 태그를 붙이고 저장한 뒤 새로고침해도 남아 있다.

### 범위

- `Note.tags: string[]` 데이터 구조, `db.json` 시드 (TD-1)
- `src/utils/tags.ts` 정규화·검증, `TagInput` 컴포넌트, `NoteEditor` 연결
- 스타일: `docs/design-system/components/tag.md`

### 완료 체크리스트

- [x] 노트 편집 화면에서 태그 입력창에 `React`를 쓰고 Enter를 **누르면**, 제목 아래에 `React` 칩이 **추가된다**.
- [x] 이미 `React` 태그가 있을 **때** `react`를 입력하고 Enter를 **누르면**, 칩이 추가되지 않고 "이미 있는 태그예요"가 **표시된다**.
- [x] 칩의 ×를 **누르면**, 그 태그가 칩 목록에서 **사라진다**.
- [ ] 태그를 바꾸고 [저장]한 뒤 새로고침**하면**, 바뀐 태그가 그대로 **보인다**.
- [ ] 기존 노트의 태그를 바꾼 상태**일 때** [취소]를 **누르면**, 태그가 저장 전 상태로 **되돌아간다**.

### 남은 작업

- **5번 미충족**: 편집 모드에서 [취소]는 `App.handleDone` → `setIsCreating(false)`만 호출한다. 이미 `false`라서 화면이 다시 그려지지 않고,
  `NoteEditor`의 폼 동기화 `useEffect`도 실행되지 않아 수정한 태그(제목·내용 포함)가 화면에 그대로 남는다. 저장은 되지 않으므로 새로고침하면 원래대로 보인다.
  - `spec-fixed.md` 4.3의 "[취소]를 누르면 태그 변경도 버려진다"와 다르다.
  - 수정 방향: `NoteEditor`에서 취소 시 `selectedNote` 값으로 `title`/`content`/`tags`/`tagDraft`를 되돌린 뒤 `onDone()` 호출. `NoteEditor` 테스트 추가.

## #2 태그 클릭으로 메모 필터

**상태**: 할 일
**요구사항**: `prd.md` F2 · 기술 결정 TD-2

### 화면에서 확인하는 방법

사이드바 노트 카드에 태그가 보이고, 태그를 클릭하면 목록이 그 태그의 노트만으로 줄어든다. 목록 위 `#태그 ×`로 필터를 푼다.

### 범위

- `NoteItem`: 태그 칩 표시(최대 3개 + `+N`), 칩 클릭 시 `onTagClick(tag)` 호출 + `e.stopPropagation()`(카드 선택 방지)
- `App`: `activeTag: string | null` state, `NoteList`에 `activeTag`·`onTagClick`·`onClearFilter` 전달
- `NoteList`: `hasTag`로 필터링, 필터 표시(`#태그 ×`, 개수), 결과 없음 화면
- 문서 먼저: `docs/design-system/components/tag.md`에 "카드 태그(클릭형)"·"필터 표시" 변형 추가 → 구현
- 테스트: `NoteList` 필터 동작, `NoteItem` 칩 클릭이 카드 선택을 일으키지 않는지

### 완료 체크리스트

- [ ] 노트에 태그가 있을 **때** 사이드바를 **보면**, 그 노트 카드에 태그 칩이 최대 3개까지 **보인다** (4개 이상이면 `+N`).
- [ ] 카드의 `React` 칩을 **클릭하면**, 목록에 `React` 태그가 붙은 노트만 남고 목록 위에 `#React ×`와 걸러진 개수가 **표시된다** (그 카드의 노트는 열리지 않는다).
- [ ] `React`로 필터 중일 **때** 다른 카드의 `공부` 칩을 **클릭하면**, 필터가 `공부` 하나로 **바뀐다**.
- [ ] 필터 표시의 ×를 **누르면**, 전체 노트 목록이 다시 **보인다**.
- [ ] 필터 중인 태그를 편집 화면에서 모든 노트에서 지워 결과가 없을 **때** 저장**하면**, "'React' 태그가 붙은 노트가 없어요"와 [필터 해제] 버튼이 **표시된다**.

태그 색상, 태그 이름 수정, 자동완성, 태그 여러 개 동시 필터 → `prd.md` 5장
